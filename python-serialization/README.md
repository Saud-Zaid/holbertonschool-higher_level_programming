# Python - Serialization

This project covers data serialization and deserialization in Python using various formats and modules including JSON, Pickle, CSV, and XML.

## Learning Objectives

- Understand the concept of serialization and deserialization
- Serialize Python data structures to JSON files and deserialize them back
- Serialize and deserialize custom Python class instances using `pickle`
- Convert tabular data from CSV format into JSON format
- Serialize Python dictionaries to XML format and parse XML files back into dictionaries

## Tasks

| File | Description |
| ---- | ----------- |
| [task_00_basic_serialization.py](./task_00_basic_serialization.py) | Basic serialization and deserialization using Python's `json` module. |
| [task_01_pickle.py](./task_01_pickle.py) | Pickling and unpickling custom Python objects using the `pickle` module with exception handling. |
| [task_02_csv.py](./task_02_csv.py) | Converting CSV data into JSON format using `csv.DictReader` and `json` module. |
| [task_03_xml.py](./task_03_xml.py) | Serializing and deserializing dictionaries using XML (`xml.etree.ElementTree`). |
