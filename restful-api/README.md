# RESTful API

This directory contains tasks for exploring and developing RESTful APIs in Python, covering consumption of third-party APIs, simple HTTP server implementation, web development with Flask, and API security/authentication.

## Tasks

| File | Description |
| ---- | ----------- |
| [task_02_requests.py](./task_02_requests.py) | Consumes posts data from JSONPlaceholder API using `requests` and exports parsed data to `posts.csv`. |
| [task_03_http_server.py](./task_03_http_server.py) | Implements a simple HTTP server using Python's standard `http.server` module with routing and JSON endpoints. |
| [task_04_flask.py](./task_04_flask.py) | Builds a basic RESTful API using Flask with routes for serving usernames, user details, API status, and adding users via POST. |
| [task_05_basic_security.py](./task_05_basic_security.py) | Implements basic HTTP authentication with `Flask-HTTPAuth` and JWT authentication with role-based access control via `Flask-JWT-Extended`. |
